Tarikh Berkuat Kuasa: 25 September 2026

MST Import and Export Sdn. Bhd. (“MST”, “kami” atau “kita”) boleh menggunakan kuki dan teknologi serupa di laman web kami untuk memastikan fungsi teras berjalan dengan lancar serta menyokong pilihan pelawat.

Dasar Kuki ini menerangkan cara kuki digunakan dan cara anda boleh mengurus pilihan anda. Dasar ini hendaklah dibaca bersama dengan Dasar Privasi dan Terma & Syarat kami.

1. Apakah Itu Kuki?

Kuki ialah fail kecil yang disimpan pada peranti anda apabila anda melawat laman web. Kuki membantu laman web beroperasi dengan betul, mengingati pilihan dan memahami penggunaan laman web.

2. Bagaimana Kami Boleh Menggunakan Kuki

MST boleh menggunakan kuki dan teknologi serupa untuk:

  • Mengendalikan fungsi teras laman web
  • Mengingati pilihan pelawat
  • Menyokong tetapan bahasa atau paparan
  • Meningkatkan prestasi laman web
  • Memahami trafik laman web
  • Meningkatkan pengalaman pengguna
  • Menyokong keselamatan laman web
  • Menganalisis penggunaan laman web
  • Menyokong fungsi laman web pihak ketiga jika diaktifkan

Kuki pilihan atau teknologi serupa akan digunakan mengikut pilihan kuki pelawat dan perkhidmatan yang diaktifkan di laman web.

3. Jenis Kuki

  • Kuki Penting (Essential Cookies): Kuki ini mungkin diperlukan untuk fungsi asas laman web, pengendalian sesi, keselamatan dan fungsi lain yang diperlukan untuk laman web beroperasi. Contohnya termasuk kefungsian sesi, keselamatan, troli beli-belah dan penyimpanan pilihan persetujuan kuki.
  • Kuki Keutamaan (Preference Cookies): Kuki ini boleh mengingati pilihan pelawat seperti bahasa (EN / ZH / BM), mata wang (MYR / SGD / USD) atau tetapan paparan.
  • Kuki Analitis (Analytics Cookies): Sekiranya diaktifkan, kuki analitis boleh membantu MST memahami cara pelawat menggunakan dan berinteraksi dengan laman web.
  • Kuki Pihak Ketiga (Third-Party Cookies): Perkhidmatan pihak ketiga yang disepadukan ke dalam laman web boleh menggunakan kuki atau teknologi serupa mereka sendiri, seperti analitis, peta, media sosial, keselamatan atau komunikasi, sekiranya diaktifkan.

4. Mengurus Kuki

Pelawat boleh mengurus pilihan kuki mereka melalui Tetapan Kuki yang disediakan di laman web ini dan juga boleh mengurus atau menyahdayakan kuki melalui tetapan pelayar web mereka. Menyahdayakan kuki tertentu mungkin menjejaskan fungsi laman web.

5. Perubahan pada Dasar Kuki Ini

MST boleh mengemas kini Dasar Kuki ini apabila teknologi laman web, perkhidmatan atau keperluan yang berkenaan berubah. Sebarang versi yang dikemas kini akan diterbitkan di laman web ini berserta tarikh yang dikemas kini.
