### Page Shift & Loader Glitch Test Results

I have thoroughly tested and verified the page loader transitions across the application, specifically testing page shifts between **Home (`/en`)**, **Products (`/en/products`)**, **Walk-in Menu (`/en/walkin`)**, **About (`/en/about`)**, **Contact (`/en/contact`)**, and multilingual routes (`/zh`, `/bm`).

---

### Key Findings & Fixes Applied

1. **Root Cause of the Previous Glitch (FOUC)**:
   - Previously, page-specific `<style>` tags were placed inside `@section('content')` in child Blade templates. This caused browsers to briefly render unstyled HTML markup (such as search boxes, category filter buttons, and grid layouts) before reaching and executing the inline CSS rules.
   - **Fix**: All child view style blocks in [`shop/index.blade.php`](file:///f:/My%20AI/Sea%20Food/seafood/resources/views/shop/index.blade.php), [`home.blade.php`](file:///f:/My%20AI/Sea%20Food/seafood/resources/views/home.blade.php), [`about.blade.php`](file:///f:/My%20AI/Sea%20Food/seafood/resources/views/about.blade.php), [`contact.blade.php`](file:///f:/My%20AI/Sea%20Food/seafood/resources/views/contact.blade.php), and [`policy/show.blade.php`](file:///f:/My%20AI/Sea%20Food/seafood/resources/views/policy/show.blade.php) have been moved to `@push('styles')`, ensuring all CSS is parsed inside `<head>` before `<body>` begins rendering.

2. **Zero-Flicker Page Transition Flow**:
   - **On Click**: When clicking any internal link (e.g. *Products*, *Home*, *Walk-in Menu*), the click handler immediately displays the oceanic loader with dynamic feedback (`Loading Products...`, `Loading Home...`) and starts the progress bar.
   - **Initial Render**: In [`app.blade.php`](file:///f:/My%20AI/Sea%20Food/seafood/resources/views/layouts/app.blade.php), `#pageSwitchLoader` is the very first element inside `<body>` with `.page-switch-loader.active` defined in `<head>`, so the screen remains covered with the styled loader while the new page renders underneath.
   - **1-Second Timing**: `schedulePageLoaderFinish()` calculates `elapsed` time against `window.__pageLoadStartTime` and smoothly fades out after **1000ms (1 second)** once the page is fully styled and ready.
